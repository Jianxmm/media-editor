# 统一完整文稿整理标准

本标准适用于视频、播客、演讲、课程、访谈、圆桌、会议问答、直播及现有转写稿。所有完整整理使用同一质量要求，按 [任务入口与方法选择](routing.md) 启用所需方法。仅在用户明确要求摘要、原始逐字稿等其他产物时调整输出目标，不把完整整理降为摘要。

## 共同质量要求

质量顺序是：事实与归属正确 → 有效内容和逻辑完整 → 原有措辞及互动 → 可读性 → 标题排版。

1. **忠实。** 原始转写是待校订材料；原声、画面和已确认资料按实际可用范围核对。不补动机、心理、经历、因果或结论，不从摘要、简介和其他参考稿扩写本场内容。明显错字只在证据足够时校正；上下文只能支持候选时记录依据和不确定性。
2. **完整。** 保留观点怎样形成、论证、步骤顺序、案例前因后果、数字及单位、限制、例外、反例、犹豫和分歧。重要追问不能被一句结论替代。纯填充词、机械重复、独立调试及无效促销可清理；承载强调、情绪或关系变化的重复仍保留。不用固定字数、比例、章节数量或无效尾声凑完整。
3. **真实归属。** 不跨人拼接观点，不把问题当成回答者结论，不把主持人的判断安到嘉宾名下。实名未知不等于声音未知；可靠边界下可用稳定中性称谓。ASR 标签、语义推断和强制聚类不能单独确认人物或换人。
4. **保留表达。** 默认轻度校订，让原有措辞、比喻、态度和现场往返可辨认。修标点断句、合并同人碎片、分短段；同一已核说话人连续讲述同一话题时只署名一次，下分自然段，来源仍逐段保留。不跨有效插话、话题切换或不明换人边界合并，也不只因候选标签相同就认作连续同人。不擅自把边想边说改成编辑编出的三点论。按自然话题加导航，话题内保留推进顺序；重组或实质删改记录来源和理由。正文不写成反复“转写中提到”的旁观者摘要。
5. **可反查。** 先通读盘点，再编辑完整底稿和阅读稿，最后从原文逐段反查事实、归属、遗漏、重复、限制、问答和结尾；不能从已写稿件倒填一份假覆盖表。记录每段源位置及关键取舍；音视频疑点有真实时间，文字无时间用段落/行号，不杜撰定位。来源覆盖、机器计数和字词相似度只能提示风险，不能证明语义质量。
6. **交付完整。** 主交付为整理成稿与待核清单；内部保留来源对应、覆盖、完整底稿、编辑取舍与质检。局部待核允许附在完成编辑的稿件中；大范围事实、归属或覆盖缺口不能称为完整成稿。编辑、原声核对、人工发布终审分别陈述，不自动发布或发送。

## 执行顺序

1. 检查输入、用户产物要求与证据能力；已有完整转写优先使用，原件只读。有本场词库时按 [共用词库](personalization.md) 保存快照，本场事实优先。
2. 通读全场，按自然话题记录时间/原段、观点、例子、限制、数字、问答和分歧。长或复杂材料覆盖前中后和所有话题，分块边界单独检查。
3. 有原声时定位关键疑点；无真实回听能力则保留实际状态，不能用辅助 ASR 代替听清。缺段、重叠、说话人和身份疑点按影响范围处理。
4. 按内容特点逐段编辑，保留有效底稿；阅读稿清理机械噪音、优化段落和导航，重要信息不得只留在内部材料。
5. 从来源逐链反查正文，再独立通读；逐项检查新增、遗漏、归属、条件、重复和结尾。记录已检查项及仍不能确认的范围。
6. 按 [待核清单](review-list.md) 列原句、定位、问题、正文采用写法与核对入口；核对两份主文件和链接可用性，按真实完成状态交付。

本地转写还要检查切点和未识别时间候选。空白可能是静音、音乐或漏识别；无达到阈值的空白不证明完整。原始逐字稿保留原文与顺序，修订副本另存。已有人工稿优先承接，不用机器基线覆盖。

待核清单为空也注明“本轮未发现可列出的疑点，不代表已核实全部事实”。只取得文字时可编辑文字，但不能声称音频准确率已经验证。没有真人核查记录不称为人工终审。
