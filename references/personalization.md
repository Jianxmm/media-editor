# 各种素材共用一份本机词库

开始前检查本工作区的“我的文稿资料”，或用户指定的目录；不搜索其他项目。没有词库也能整理。可用同一份资料处理文字、播客、视频和直播，未确认词不能变成默认事实。本场明确资料优先于长期词库；冲突保留待核。

使用内置直播核心的原有六列词库与资料快照格式，不另造一套。让助手执行：

```text
python <SKILL_ROOT>/scripts/workspace_tools.py profile init <资料目录>
python <SKILL_ROOT>/scripts/workspace_tools.py profile check <资料目录>
```

普通文字、视频和播客任务，用 `profile snapshot <资料目录> --workspace <本次任务目录>` 保存本次快照；编辑读取 `_work/个人资料/` 中的词库与偏好，不擅自追随后来版本。参考稿仅按资料索引明确指定的范围读取，不移植参考稿事实。

直播任务仍给核心 `init` 传入 `--profile <资料目录>`，使用其原有快照流程；不要先建立目录再让 init 覆盖。未执行或未绑定的资料不能伪称已载入。

本地转写可加 `transcribe ... --profile <资料目录>`：只将通过已有词库检查的已确认专名作为本地识别提示，并保存资料快照。识别提示不能证明原话实际出现，也不自动替换原稿、判断说话人或关闭待核问题。没有这项参数时不声称转写用过词库。

资料放在技能目录外，不随升级覆盖，不写入 GitHub 或公共示例。本工具只调用本机转写器；云端传输仍按用户授权处理。
