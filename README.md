重点面向 **2–3 小时的直播分享与双人访谈**。留下讲述中的例子、细节和真实问答，把需要回听确认的地方单独列清楚。普通视频、播客和已有文字，也可以用同一套规则整理。

## 三步开始

### 1. 下载，解压

点击上面的绿色按钮，或 [下载最新版](https://github.com/Jianxmm/media-editor/releases/latest/download/media-editor.zip)。解压后得到一个 `media-editor` 文件夹。

### 2. 交给 AI 助手安装

把**整个文件夹**交给你平时使用的 AI 助手，或者告诉它文件夹在电脑里的位置，再复制这句话：

```text
请帮我安装这个“文稿整理”Skill，按文件夹里的说明完成安装。
```

安装完成后，开启新对话。只装这一个，直播整理规则已经包含在里面。

<details>
<summary>想让 AI 直接下载安装？复制这一句</summary>

```text
帮我安装“文稿整理”Skill：https://github.com/Jianxmm/media-editor
请使用最新版完整安装包；已装过的话，升级前先完整备份旧版。
```

如果所用工具没有 Skill 安装入口，也可以让它从包内的 `SKILL.md` 开始读取整理规则。[详细步骤](START_HERE.md)

</details>

### 3. 发来材料，开始整理

把直播回放和转写初稿一起提供，再说：

```text
请按直播标准整理这场直播，保留原意、重要细节和真实问答。
给我待发布文稿和待核对清单两个 Markdown 文档。
完成后，把两份文件的打开链接和保存位置发给我。
```

只有视频、只有文字，或者想整理播客，也可以直接提供材料。[材料怎么给？](START_HERE.md#提供材料)

## 整理完，你会拿到两份文件

**① 待发布文稿**

理顺段落与标题，保留原话里的意思、案例和问答过程，供你审阅、修改。

**② 待核对清单**

列出哪里有疑问、原句是什么、现在怎么写，以及到哪里回听或查证。有可用的音频片段时，附上打开链接。

两份都是 **Markdown（`.md` 格式的文字文档）**，可以用笔记软件或文本编辑器打开。清单核对完、文稿审核后，再决定发布。

## 看看整理后的样子

下面节选自一段为演示编写的对谈，非真实直播记录。

**原转写**

> 主持人：你是怎么让自己坚持写下来的？
>
> 嘉宾：一开始我也做不到每天写啊。我就给自己定了个小要求，下班以后先坐下来写二十分钟，写得好不好先不管。

**整理后**

> **主持人：你是怎么让自己坚持写下来的？**
>
> **嘉宾：** 一开始我也做不到每天写。我就给自己定了个小要求：下班以后，先坐下来写二十分钟，写得好不好先不管。

保留第一人称和问答，让断句更顺。疑似错词另列清单，按原声核对。[看看完整对谈和待核清单 →](examples/整理前后.md)

## 其他材料，也可以这样用

| 你想整理什么 | 直接对助手说 |
| :--- | :--- |
| 视频、播客 | “整理这段内容，保留重要案例和细节，给我完整稿和待核清单。” |
| 已有转写稿、字幕或其他文字 | “帮我整理这份文稿，保留原意，疑点单独列出来。” |
| 只想快速看重点 | “只要摘要。” |
| 想保留每句话 | “输出原始逐字稿，保留原语言、顺序和口头词。” |
| 想边读边回听 | “保留真实时间标记，方便回听。” |

视频可以提供本地文件，也可以提供 B站视频、小宇宙播客等**单条内容的链接**。链接无法读取时，改交本地文件。

明确要求直播标准时，待发布文稿和待核清单保留，其他形式作为补充。

## 常见问题

<details>
<summary><strong>我用的 AI 工具没有 Skill 安装入口，怎么办？</strong></summary>

这套整理体系不绑定某一家 AI 产品。下载并解压后，让助手从 `SKILL.md` 开始，按任务读取引用的规则和模板。

涉及下载、转写和回听时，需要所用工具具备对应能力。日常使用直接说中文即可。[第一次使用](START_HERE.md)

</details>

<details>
<summary><strong>只有视频，或者只有文稿，可以整理吗？</strong></summary>

可以。只有音视频，先检查有没有字幕或可用的转写方式；只有文稿，就先整理文字，把需要原声确认的疑点留下。

按完整直播标准整理时，需要回放及必要的核验材料。已有转写初稿就直接用，有疑点再回听，不必重转整场。

</details>

<details>
<summary><strong>两三个小时的直播，会不会最后只剩一份摘要？</strong></summary>

按直播标准整理时，会先通读全场，再逐段整理，最后对照原稿检查重要内容是否保留。主持人的追问、嘉宾的例子和讲述过程都在整理范围内。

完整底稿和编辑记录会留在任务文件夹里，方便反查。完整直播流程面向单人分享和双人访谈。

</details>

<details>
<summary><strong>常用名字总写错，或者任务中断了，怎么办？</strong></summary>

常用姓名、公司名和术语，可以告诉助手“帮我建立文稿整理词库，以后都用这一份”。有词库可作参考，具体原话仍按来源核对。

中途断了，就说“继续上次任务，使用原来的素材和任务目录”。更新版本时说“先完整备份旧版再升级”，词库和素材保存在安装目录外。[词库、继续任务与更新](references/maintenance.md)

</details>

<details>
<summary><strong>收费吗？</strong></summary>

整理体系按 MIT 协议开源。你使用的 AI 工具、模型或转写服务可能另行计费，下载包不含账号与云额度。上传素材、付费和对外发送按你的授权执行。

</details>
