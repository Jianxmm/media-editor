# 文稿整理

把视频、播客、直播和已有文字，整理成保留原意与重要细节的文稿；拿不准的人名、数字和表达单独列出来，方便核对。

**[下载最新版](https://github.com/Jianxmm/media-editor/releases/latest/download/media-editor.zip)** · [第一次使用](START_HERE.md) · [看看结果示例](examples/整理前后.md)

这是目前唯一推荐的安装入口。下载后安装整个 `media-editor` 文件夹即可，不需要挑选不同版本或另外安装直播 Skill。

## 三步开始

**1. 下载并解压**

点击上面的“下载最新版”，解压得到 `media-editor` 文件夹，保留其中的隐藏目录和文件。

**2. 让 AI 助手帮你安装**

把文件夹交给支持 Skill 的 AI 助手，复制这句话：

> 请读取这个文件夹的 README.md 和 SKILL.md，帮我安装“文稿整理”到当前助手实际使用的技能目录。已装过的话，先检查版本；需要升级时完整备份旧版，保留我的词库和素材。安装后确认技能名称是“文稿整理”。

安装后开启新对话。Codex 可用 `$media-editor` 调用；其他客户端按其技能入口使用。WorkBuddy 的实机安装和效果仍待验证。

**3. 提供材料，说明你想要什么**

> 用文稿整理处理这份材料，保留案例、数字和原意，给我完整阅读稿和待核清单。材料在：［文件路径或单条链接］。

你可以直接粘贴文字、上传音视频、提供文件路径，或发一条视频/播客单集链接。已有转写稿就一起提供，无需重复转写整场。只有音视频时，助手会先检查字幕或可用转写工具；链接能否读取取决于平台权限和环境，不把网页简介当原文。

## 整理完会得到什么

默认主要收到两个 Markdown 文档：

- **整理稿**：保留重要内容，改善段落和表达，方便阅读与修改。
- **待核清单**：先列重要问题；同一位置的疑点归组，显示原句、当前写法、需要确认什么，以及可用的原声位置。

需要按直播标准整理时，直接说：

> 请按直播标准整理这场直播，保留原话、真实问答和追问，输出待发布文稿和待核对清单两个 Markdown。回放在［路径］，原转写在［路径］。

这会使用原有的单人分享/双人访谈规则，保留必要的核查与编辑记录。待发布稿仍需处理待核问题并完成人工审核；没有回放或实际声音核验依据时，不能宣称已经完成原声核对。三人及以上不按这套完整直播标准验收。

## 想要其他输出，直接说

| 想得到什么 | 可以这样说 |
| --- | --- |
| 完整稿，默认选择 | “整理成完整阅读稿，保留案例和推理过程，疑点单独列出。” |
| 直播标准的两份稿 | “按直播标准整理，保留原话和问答，给待发布稿和待核清单。” |
| 只看要点 | “只要摘要。” |
| 摘要加完整稿 | “在完整稿前加一段摘要。” |
| 原始逐字稿 | “保留原语言和发言顺序，不删口头词。” |
| 方便回听 | “整理成带真实时间标记的稿件。” |
| 只获取素材 | “只获取这一条音频，暂不整理。” |

明确同时要求直播标准和其他形式时，两份直播主交付仍保留，其他形式作为补充。没有可靠时间信息时不会编造时间。

## 有词库、任务中断或需要升级怎么办

**常用姓名和术语：**告诉助手“帮我建立文稿整理的词库”，或提供已有的“我的文稿资料”文件夹。文字、播客、视频和直播共用这份资料；只把有依据的词标为已确认。本地转写可以把这些词作为识别提示，但提示不等于原话已经核实。资料保存在安装目录外，升级后继续使用。

**处理到一半中断：**告诉助手“继续上次任务，使用原来的素材和任务目录”。绑定一致的下载和转写会复用已完成部分；不同链接或不匹配文件会停止，避免混用。旧版无任务记录的目录不自动猜测匹配。

**安装新版：**告诉助手“帮我升级文稿整理，先备份旧版”。重复安装相同版本保持现状；不同版本会按明确的升级操作完整备份。需要回退时，让助手使用升级时返回的备份目录恢复。

**想知道花了多久：**告诉助手“记录处理阶段并给我看耗时”。下载、转写和音频处理会记录实际工具耗时，编辑阶段可以记录开始和结束；未测量的阶段及真人核对时间保持未知，不凭调用次数估算。

## 使用条件与费用

这个 Skill 需要 AI 助手来执行，不是独立 AI 模型。已有文字主要需要文件读写；音视频处理按需使用本机或已授权的转写能力。模型、工具、账号和云额度不包含在下载包里，AI 客户端或云服务可能按自身规则计费。新服务、素材上传或费用应按你的授权处理。

本版仍为公开试用。已有本机安装、工具与短公开样例验证；真实长场质量、WorkBuddy 和其他设备仍需实测。自动转写可能有错，切点或时间空白只提示核对，不能代替听原声和人工终审。
